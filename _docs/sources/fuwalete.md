# ふわりと将棋の調査記録

取得の制約（壊すと困ること・壊れやすい点）は `scrape/AGENTS.md`。
ここはサイトの作りと実データの詳細（2026-11-18 に調査）。

## サイトの作り

- WordPress（テーマ Cocoon）のブログ。`robots.txt` が禁じているのは `/wp-admin/` だけ
- KIF・CSA・構造化データは**配っていない**。指し手は記事の本文に手で書かれている
- 記事の HTML は 700KB を超える（広告・サイドバー・CSS）。REST API
  `/wp-json/wp/v2/posts?slug={slug}&_fields=date,title,content` なら本文だけで 20KB 程度
- 記事の slug（`ito-365549`）の数字は WordPress の記事 ID と同じ

## 本文の書き方

```
△投了　18時8分
97手　92%　▲55金 0:37
96手　92%　△81飛
…
70手　84%　△36桂 ai39銀 0:20
　先手勝勢　寄せ合いで先手が速い
…
1手　51%　▲26歩

 　　ーー 対局 開始 ーー
```

- **新しい手が上。** 段落（`<p>`）が盤面の画像を挟んで分かれ、行は `<br>`
- `{手数}手　{評価値}%　{▲△}{指し手}` のあとに空白区切りで付記が続く
  - 指し手は **KI2**（移動元なし）。移動先は算用数字（`55`）、「同」は空白なし（`同玉`）、
    修飾（`53銀引成`）は付く、打ちの「打」は付かない（`55金` が打ち）
  - 付記: `0:37`（残り時間）、`18/0:52`（消費/残り）、`2`（消費の分）、`ai39銀`（AI の推奨手）
- 字下げした行（`　先手勝勢　…`）は直前の手の解説。`ーー 午後 開始 ーー` などの区切りもある
- 見出し `<h2 id="live">` に `後手△伊藤叡王　先手▲永瀬九段`（呼び名）
- 題は `11.6(金) 王将戦 挑決L 伊藤匠 永瀬拓矢 10時～棋譜速報`（年は無い。投稿は前日のこともある）
- 「持ち時間：4時間」は本文の対局条件の段落にある

## 対局中

記事の本文には途中までの手しかなく、最新の手は**共有の枠のページ**（WordPress の固定ページ。
例 `/q22b/`）にある。記事は次の JS で枠を 15 秒ごとに読み込んで `<div id="listeva">` に差し込む:

```js
var url = "https://fuwalete.com/q22b/"; var div = document.getElementById('listeva'); ajaxUpdate(url, div);
```

- 枠の本文には見出し（`後手△広瀬九段　先手▲豊島九段`）と、記事にまだ移していない最新の手
- 枠は**同時に中継している対局ごとに 1 つ**で、別の日には別の対局に使い回される
- 終局すると記事に全部の手と見出しが移り、この JS は消える
